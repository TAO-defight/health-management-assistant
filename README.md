# AI 健身与营养规划助手

一个本地运行的网页应用，包含分步身体数据采集、体脂秤图片识别接入、伤病保护、训练与饮食方案、PDF 下载，以及两周后的复盘迭代。

## 运行

```bash
python3 -m pip install -r requirements.txt
./run.sh
```

打开 `http://127.0.0.1:4173`。

## 图片识别

配置 OpenAI API 密钥后，体脂秤截图会发送给视觉模型识别：

```bash
OPENAI_API_KEY=your_key ./run.sh
```

也可用 `OPENAI_VISION_MODEL` 指定支持图片输入的模型。未配置密钥、图片模糊或结果未通过合理性校验时，页面会要求手动填写，不会猜测数据。

## 隐私与安全

- 服务端不建用户数据库；两周复盘所需的最近计划仅存于当前浏览器。
- 身高、体重、体脂率等会在前后端分别进行范围校验。
- 训练计划会根据报告的疼痛部位替换高风险动作；未明确部位的伤痛只安排保守无痛活动。
- 本建议由 AI 生成，仅供参考，不构成医疗建议。剧烈运动前请咨询专业人士。
